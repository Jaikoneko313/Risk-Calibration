## Tools

### 🎯 Risk Calibration Calculator
[`calibration_calculator.html`](./calibration_calculator.html) — เครื่องมือช่วย score ความเสี่ยง (P × I) ให้ consistent ทั้งทีม

**ใช้ทำอะไร:**
- ดู rubric ของ Probability และ Impact
- คำนวณ % delay ได้ทันที (interactive)
- mapping ผลลัพธ์ไปคะแนน Impact (Low / Moderate / Significant / Severe)

**สำหรับใคร:**
- L2 Initiative Owners
- L3 L-R Hands (Contributors)
- PMO Office
